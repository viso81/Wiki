# pacman
安装/卸载/查询软件包

## 命令
```bash
sudo pacman -S package_name   # 安装
sudo pacman -R package_name   # 卸载（保留依赖）
sudo pacman -Rns package_name # 卸载并清除依赖
sudo pacman -Syu              # 更新系统

pacman -Q  # 查看所有已安装软件,包含依赖
pacman -Qe # 只显示主动安装的软件，不包含依赖
pacman -Qm # 只看来自AUR的软件（yay/paru)
pacman -Qn # 只看来自官方的软件

pacman -Qqe # 官方仓库主动安装包
pacman -Qqm # AUR主动安装包

sudo pacman -Qdt                # 清理孤立包
sudo pacman -Rns (pacman -Qdtq) # 连同配置文件一起清理

sudo pacman -Sc # 只保留每个包最近的1-2个版本，清楚旧版本缓存
```

## 备注
- `-Syyu` 强制刷新数据库，遇到404报错时用
